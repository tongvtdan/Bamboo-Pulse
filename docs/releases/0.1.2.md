# Bamboo Pulse 0.1.2 beta

Bamboo Pulse is a macOS menu-bar app for following local Codex sessions. This release is intended for early testing and should be published as a GitHub prerelease, not the latest stable release.

## Included

- Working, Needs you, Turn ended and Unknown session states.
- Normal bamboo and compact menu-bar layouts, display preferences and attention notifications.
- User-triggered navigation to a validated live chat.
- Labeled synthetic Preview sessions without enabling monitoring.
- Bundled local runtime with consent-based setup and removal that preserves user-owned configuration.

Turn ended does not confirm task success.

## Requirements and installation

The complete package requires Apple silicon. The app deployment target is macOS 14, but automated checks were run on macOS 27.2 only; earlier versions are not yet qualified. Live monitoring expects the supported Codex executable inside `/Applications/ChatGPT.app`.

Download `Bamboo-Pulse-0.1.2-arm64.dmg`, open it, drag Bamboo Pulse to Applications and launch it. Follow the [Quick Start](../quick-start.md) to enable monitoring or remove it. Setup requests consent before adding Codex hooks and a shell startup block.
