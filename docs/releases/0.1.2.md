# Bamboo Pulse 0.1.2 beta

Bamboo Pulse is a macOS menu-bar app for following local Codex sessions. This release is intended for early testing and should be published as a GitHub prerelease, not the latest stable release.

## Included

- Working, Needs you, Turn ended and Unknown session states.
- Normal bamboo and compact menu-bar layouts, display preferences and attention notifications.
- User-triggered navigation to a validated live chat.
- Labeled synthetic Preview sessions without enabling monitoring.
- Bundled local runtime with consent-based setup and removal that preserves user-owned configuration.

Turn ended does not confirm task success.

## Requirements and installation

The complete package requires Apple silicon. The app deployment target is macOS 14, but automated checks were run on macOS 27.2 only; earlier versions are not yet qualified. Live monitoring expects the supported Codex executable inside `/Applications/ChatGPT.app`.

The DMG includes the monitoring runtime; Xcode and a separate Python installation are not required.

1. Download `Bamboo-Pulse-0.1.2-arm64.dmg`, open it, and drag **Bamboo Pulse.app** to **Applications**.
2. Launch the installed app and choose **Enable monitoring**. Setup requests consent before adding Codex hooks and a shell startup block.
3. Quit ChatGPT completely and reopen it to load the monitoring configuration.
4. Open a **local Codex chat**. Click **Hooks** beside the message box, review the seven Bamboo Pulse commands, and enable or approve them. With a local project open, these are also listed under **Settings → Hooks**.
5. **After enabling the hooks, quit and reopen both ChatGPT and Bamboo Pulse.** Keep Pulse in Applications while monitoring is enabled.
6. Start a new local Codex task and click the bamboo menu-bar icon. Confirm the session appears without a **DEMO** badge. Enable **Settings… → Display → Show session status** if you want text states.

For notifications, enable **Notify when a session needs you** in Pulse Settings, allow macOS notifications, and choose **Send test notification**. Follow the [Quick Start](../quick-start.md) for detailed setup, troubleshooting, and removal instructions.

The release owner reported successful live monitoring on a new test machine after enabling the hooks and restarting both apps on 4 November 2026. Permission refusal, monitoring recovery, and removal results have not yet been recorded here.
