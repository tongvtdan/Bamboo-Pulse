# Release checks

For a source release, verify a clean clone can run Preview, pass both native test schemes and build unsigned with the documented tools. Confirm the license and provenance of every distributed asset and dependency.

For a downloadable app also verify the exact signed artifact, dependency notices, notarization and normal browser download on a clean Mac. Record first real observation, chat navigation, permission refusal, loss and recovery of monitoring, and clean removal. Record which macOS versions and architectures actually passed.
