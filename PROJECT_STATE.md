# Bamboo Pulse project state

The [repository](https://github.com/tongvtdan/Bamboo-Pulse) contains the contributor project for the macOS menu-bar app. The source candidate targets version 0.1.2 (build 102). Its source-level checks cover Preview, Live fixtures, an unsigned Release build and a locally supplied runtime interpreter. The public-source candidate has no signed binary tied to its revision. A public binary release requires a separate artifact review. Source version and minimum deployment target do not establish the tested operating-system range.

Use [the workflow](WORKFLOW.md) to record results against each contribution. For a handoff include the commit or working-tree diff, the checks actually run, unresolved failures and the next reproduction step. Chat naming is optional and no public project prefix is assigned.
