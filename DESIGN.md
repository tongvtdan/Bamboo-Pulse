# Menu-bar design

Start at the menu-bar icon. Opening the popover should answer which session needs attention and whether the observation is current. Use the existing session labels **Working**, **Needs you**, **Turn ended**, and **Unknown**. Pair color with a label or symbol.

Keep Preview visibly synthetic. Live must distinguish an empty feed from missing, invalid or expired evidence. Preserve keyboard access, accessible labels and reduced-motion behavior when changing a row, badge or menu. Review text clipping and focus in the popover at its actual width.

For visual changes include a Preview screenshot with sample data. For changes to live states also include the fixture that produced the result. See [behavior](SPEC.md).
